# Data Directory
# ===============

The GoEmotions dataset is automatically downloaded from HuggingFace
when you run training or evaluation.

Dataset Information:
--------------------
- Name: GoEmotions (Google)
- Source: https://huggingface.co/datasets/go_emotions
- Size: ~58,000 Reddit comments
- Labels: 27 emotions (+ neutral, which we exclude)

The dataset is cached automatically by HuggingFace Datasets library.
No manual download is required.

Reference:
----------
Demszky et al., "GoEmotions: A Dataset of Fine-Grained Emotions"
ACL 2020 - https://arxiv.org/abs/2005.00547
